# CFD Result Images

This directory contains selected visual results from the periodic-hill CFD study.

The figures highlight:

- Computational domain and mesh
- Grid-independence study
- Residual convergence
- Velocity profiles
- Vorticity and flow structures
- Q-criterion visualization
- Numerical-scheme sensitivity
- Solver-parameter sensitivity

The images were selected to provide a concise overview of the CFD methodology and the most important numerical results.
